# QS-A-008 原版复刻规格

参照文件：`rs_report_20261030_from_cai.html`，来自菜老师，数据截止日为 2026-10-30。原报告附属脚注、表格和 Plotly trace 已一并核对。

## 数据范围与分组

- 行业榜单：31 个申万一级行业。
- 宽基榜单与 RS 网格：16 个指数，按各自榜单 RS 分降序。
- 热力图和象限图：31 个行业 + 6 个核心宽基 + 沪深300基准，共 38 个对象。
- 核心宽基：上证指数、中证2000、中证1000、中证500、科创50、创业板指。
- 历史线图：250 个交易日；热力图：120 个交易日。
- 统一基准：沪深300。
- 日线字段使用指数收盘价；行业通过 Tushare `sw_daily`，宽基与基准通过 `index_daily`。
- 原版提到的数据体系为 `a-stock-data-updaters (stock-main-index-data / sw-index-data)`。本项目用 Tushare 对应日线，并在固定截止日逐项与原报告序列核验。

## 指标口径

- RS 线：`指数收盘 / 沪深300收盘`。乘以常数 100 不改变状态或收益率。
- MA20：RS 线过去 20 个交易日的简单移动平均；先在完整历史序列上计算，再截取图表显示窗口。
- 状态：RS 线高于 MA20 为“强”，否则为“弱”。
- 持续：当前状态连续保持的交易日数。
- 今日信号：昨日弱、今日强为“新转强”；昨日强、今日弱为“新转弱”。
- 超额 N 日：`RS线(t) / RS线(t-N) - 1`，N 为交易日数，N 取 20、60、120。
- RS 原始分：`0.5×超额20d + 0.3×超额60d + 0.2×超额120d`。
- 单日相对涨幅：`RS线(t) / RS线(t-1) - 1`，即对象单日涨幅相对沪深300的复合超额；另列对象指数自身单日涨幅用于区分绝对上涨与相对走强。
- RS 分：各自榜单横截面内对原始分计算 z 分数，使用总体标准差，再取标准正态累积分布函数 × 100；范围 0–100，50 为组内均值。
- 分Δ：当日 RS 分减去上一交易日 RS 分，不是排名变化。
- 动量40d：行业指数绝对收益 `收盘(t) / 收盘(t-40) - 1`；≥3% 显示勾选标记。

## 六大板块

1. 行业 RS 榜单：31 行，列为排名、名称、RS原始分、RS分、分Δ、状态、持续、今日信号、20/60/120 日超额、40 日绝对动量。RS原始分以百分数展示；RS分是其横截面标准化分。
2. 行业 × 宽基热力图：38×120；每日对 38 个对象的加权原始分做合并横截面 RS 分；按报告末日 RS 分从强到弱排列；色阶固定 0–100，弱值绿、强值红（原 Plotly colorscale 使用反转 RdYlGn）。
3. 超额动量象限：横轴 60 日超额，纵轴 20 日超额；31 行业用圆点，6 核心宽基和沪深300用菱形；原点是沪深300基准，右上为双强。
4. 最强 / 最弱行业 RS 线：榜单最高 5 与最低 5；同一上方坐标轴；10 条 RS 线以各自首个显示交易日归一到 100，MA20 用同色虚线；下方独立绘制同期沪深300价格并归一到 100。
5. 大盘 / 宽基 RS 网格：按 16 指数榜单分两组；榜单含RS原始分和RS分。每个指数以该图表窗口首日的指数/沪深300比值归一到 100，叠加其完整历史计算的 MA20 和 y=100 灰色虚线。第一组还在首格显示归一化沪深300基准走势。
6. 单日相对涨幅 / 反转提示：31 个行业、6 个核心宽基和沪深300基准，共38项。列示指数单日绝对涨幅、单日相对涨幅、前日/当日RS状态及提示；按单日相对涨幅降序。前日弱且单日相对涨幅为正，标记“弱势反弹”；前日强且单日相对涨幅为负，标记“强势回撤”；若当日RS状态发生切换，优先显示“趋势转强/趋势转弱”。这些短线提示不替代RS线与MA20的趋势状态定义。
